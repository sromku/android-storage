1 · Start the collector

Run this on your computer from the repo root:

python3 tools/companion.py

This dashboard is served at http://localhost:8899.

2 · Connect the app

In the app: Settings → External collector → enable, then paste one of these URLs.

Same Wi-Fi

http://…:8899

USB (adb tunnel)

./tools/adb-reverse.sh
http://127.0.0.1:8899
3 · Browse device files

The Files tab reads the device over adb (USB or wireless debugging). Connect the phone with adb and it mirrors the filesystem here — traverse folders, multi-select, and download to this computer.

4 · Unlock the app's power (Shizuku)

The app's advanced features — System, Network, Permissions, Provider watch, App-ops, decompilation — need a privileged shell via Shizuku (or root). The companion's Files tab uses plain adb and doesn't need it.

  1. Enable Settings → Developer options → Wireless debugging.
  2. Open the Shizuku app → Start via Wireless debugging (no computer needed).
  3. Grant Shizuku access to Storage Studio when it prompts — once per app version.
Non-root Shizuku stops on every reboot — repeat step 2 to restart it after a restart. If Shizuku itself won't start on a brand-new Android version, update the Shizuku app.
